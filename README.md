# 🎞️ Arizona Display Reel

An interactive 3D display reel built with **React**, **TypeScript**, **GSAP**, and **Three.js**.  
This project showcases two 3D models and an animated video carousel, designed to deliver a sleek, immersive portfolio or presentation experience.

---

## 🛠 Tech Stack

- **React** – UI library for building component-based interfaces  
- **TypeScript** – Strong typing for safer and scalable code  
- **GSAP** – High-performance animation library  
- **Three.js** – WebGL-powered 3D rendering  

---

## ✨ Features

- 🎥 **Animated Video Carousel** — Smooth transitions between embedded videos  
- 🧊 **3D Model Display** — Load and render two interactive 3D objects  
- 📱 **Responsive Design** — Optimized for both desktop and mobile  
- 💨 **GSAP Animations** — Timeline-based motion and interactivity  
- ⚙️ **Component-Based Architecture** — Easy to maintain and expand  

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/arizona-display-reel.git
cd arizona-display-reel
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```

The project will run on [http://localhost:3000](http://localhost:3000).

---

## 📁 Project Structure

```
/public            → Static files (3D models, video assets)
/src
  /components      → Reusable UI and 3D components
  /models          → 3D model loaders and logic
  /styles          → SCSS/CSS files
  /utils           → Helper functions
  App.tsx          → Root component
  main.tsx         → Entry point
```
